# Zomato Dataset Analysis

## Project Overview
This project analyzes Zomato restaurant data to find insights about ratings, cuisines, customer preferences, pricing, and restaurant locations using Python.

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Features
- Data Cleaning
- Restaurant Rating Analysis
- Cuisine Analysis
- Location Analysis
- Data Visualization

---

## How to Run the Project

1. Download the notebook file
2. Open it using Google Colab
3. Upload the dataset file
4. Run all cells
